# 한글문서 자동작성 스킬 v2

사용자는 문서를 먼저 올려도 되고 대화를 먼저 해도 된다.

- 문서 → 대화 → "이제 문서 작성해줘"
- 대화 → 문서 → "이 문서 작성해줘"

핵심 원칙:
1. 문서 첨부 순서에 의존하지 않는다.
2. 최신의 명시적 사용자 확정값을 우선한다.
3. 확인되지 않은 날짜·장소·인원·금액·연락처·개인정보는 추측하지 않는다.
4. 정보가 없으면 `확인 필요`.
5. 기존값과 최신값이 다르면 교체 전/후를 보여준다.
6. 승인된 값만 반영한다.
7. 원본 파일은 덮어쓰지 않는다.
8. 사진은 사용자가 제공한 파일만 사용한다.
9. 결과 파일은 재검증한다.

대화 자체가 데이터 원본이며 사용자가 `항목: 값`을 다시 입력할 필요가 없어야 한다.
