# 한글문서 대화형 자동작성 스킬

## 목표

사용자는 다음 두 방식 중 어느 쪽으로도 작업할 수 있다.

A. 한글문서 첨부 → 대화 → "이제 문서 작성해줘"
B. 대화 → 한글문서 첨부 → "이 문서 작성해줘"

문서 첨부 순서에 의존하지 않는다.

## 기본 절차

1. HWP/HWPX 문서를 `한글자동작성 분석`으로 읽는다.
2. 문서가 요구하는 항목, 기존값, 표, 필드, 사진 위치를 파악한다.
3. 현재 작업과 관련된 대화에서 사실을 추출한다.
4. 같은 항목의 값이 여러 번 나오면 가장 최근의 명시적 사용자 확정값을 우선한다.
5. 문서 기존값과 대화 최신값을 비교한다.
6. fill / replace / keep / review 로 분류한다.
7. 사용자에게 변경 미리보기를 보여준다.
8. 승인된 내용만 실행계획 JSON으로 만든다.
9. `한글자동작성 작성`으로 문서를 생성한다.
10. `--verify` 및 `한글자동작성 검증`으로 결과를 재검증한다.
11. 원본 파일은 수정하지 않는다.

## 절대 규칙

- 사용자가 `항목: 값`을 다시 입력하도록 요구하지 않는다.
- 대화에서 확인되지 않은 날짜, 시간, 장소, 인원, 금액, 연락처, 계좌, 개인정보를 추측하지 않는다.
- 문서에 과거 값이 있어도 그것을 최신 사실로 간주하지 않는다.
- 최신 확정값과 기존값이 충돌하면 자동으로 숨기지 말고 변경 전/후를 보여준다.
- 낮은 신뢰도는 `확인 필요`로 처리한다.
- 사진은 사용자가 제공한 파일만 사용한다.
- 결과 파일이 검증에 실패하면 성공했다고 말하지 않는다.

## 문서 항목 의미군

프로그램명 = 프로그램명/교육명/강의명/과정명/사업명/행사명/주제
일시 = 일시/교육일/강의일/날짜/운영일/일자
장소 = 장소/교육장소/강의장소/위치
대상 = 대상/교육대상/참여대상/참가대상
인원 = 인원/교육인원/참여인원/참석자수
내용 = 내용/강의내용/교육내용/주요내용/세부내용/활동내용
목표 = 목표/교육목표/운영목표
강사명 = 강사명/강사/성명/담당강사
연락처 = 연락처/전화번호/휴대전화/휴대폰

## 실행계획 JSON

```json
{
  "edits": [
    {"action":"set_cell","locator":"0:1:2","value":"2026년 09월 17일"},
    {"action":"replace","find":"2025 디지털 역량강화 교육","value":"주민자치 힐링 프로그램"}
  ],
  "photos": [
    {"anchor":"활동사진 1","path":"사진1.jpg","size_mm":"70x50"}
  ]
}
```

지원 edit action:
- set_cell
- set_field
- replace
- insert_paragraph

사진은 `anchor=>path@WxH(mm)` 방식으로 삽입하며, 작성 후 검증한다.
