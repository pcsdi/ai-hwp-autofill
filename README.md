# AI HWP/HWPX AutoFill v1

범용 한글(HWP/HWPX) 서식 자동작성 웹앱 1차 프로토타입입니다.

## 목표
- HWP/HWPX 업로드
- 문서 텍스트/표 구조 분석
- 사용자가 입력한 작성내용을 문서 항목과 자동 매칭
- HWPX의 빈 셀/플레이스홀더에 텍스트 삽입
- 사진 업로드 및 사진 영역 후보 탐지
- 원본은 보존하고 새 HWPX 파일 생성

## 현재 지원 범위
- HWP: 읽기/구조 분석 중심
- HWPX: 읽기 + 텍스트 치환 + 제한적 사진 삽입
- 암호화/배포용 HWP, 복잡한 글상자/누름틀/도형은 예외가 있을 수 있음

## 실행
1. Python 3.10+ 설치
2. `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`
4. 브라우저에서 `http://127.0.0.1:8000`

## 안전 원칙
- 원본 파일을 덮어쓰지 않습니다.
- 확실하지 않은 항목은 자동 입력하지 않고 확인 대상으로 남깁니다.
- 업로드한 문서는 로컬 임시 폴더에서 처리하며 외부 전송 기능은 포함하지 않았습니다.
