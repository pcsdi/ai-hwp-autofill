# 한글문서 자동작성 엔진 1

AI와 대화한 내용을 HWP/HWPX 문서에 자동 반영하기 위한 로컬 처리 엔진입니다.

## 핵심 구조

- **스킬**: 대화에서 최신 확정 정보를 찾고, 문서 항목과 의미 기반으로 매칭합니다.
- **엔진**: HWP/HWPX를 실제로 읽고, 셀/필드/텍스트/사진을 수정하고 검증합니다.
- **기반 엔진**: `hwp-cli`를 사용합니다.

## 설치

1. Python 3.10 이상 설치
2. `hwp-cli` 설치 후 `hwp` 실행파일을 PATH에 추가
3. 이 폴더에서:

```bash
pip install -e .
```

## 사용 예

### 문서 분석

```bash
한글자동작성 분석 "양식.hwp" -o 분석.json
```

### 문서 작성

```bash
한글자동작성 작성 "양식.hwp" "계획.json" -o "완성본.hwp"
```

### 결과 검증

```bash
한글자동작성 검증 "완성본.hwp"
```

### 첫 페이지 미리보기

```bash
한글자동작성 미리보기 "완성본.hwp" -o "미리보기.png"
```

## 중요한 점

이 엔진 자체가 AI 대화 기록을 직접 가져오는 것은 아닙니다.
AI 스킬이 현재 대화에서 최신 확정정보를 구조화하고 실행계획 JSON을 만든 뒤,
엔진이 실제 HWP/HWPX 파일에 적용하는 구조입니다.

즉 사용자 경험은:

`AI와 대화 → HWP/HWPX 첨부 → 이 문서 작성해줘 → 완성 한글파일`

로 만들 수 있습니다.
