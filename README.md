# 한글문서 자동작성 엔진 2

AI 대화 → 문서 분석 → 의미 매칭 → 사용자 확인 → HWP/HWPX 작성 흐름을 위한 2차 버전입니다.

## 목표 사용 방식
`이 대화 내용으로 첨부한 한글문서 작성해줘.`

## 기반
Windows에서 hwp-cli 0.11.x로 다음 동작이 확인된 흐름을 기준으로 설계했습니다.
- HWP 정보 읽기
- HWP 본문 추출
- 기존 HWP 수정
- 새 HWP 저장

## 핵심 명령
- `한글자동작성 분석`
- `한글자동작성 제안`
- `한글자동작성 작성`
- `한글자동작성 검증`

## 주의
문서마다 표 구조가 달라 완전 자동 셀 좌표 탐지는 추가 보완이 필요할 수 있습니다.
v2는 실제 HWP 읽기/쓰기 엔진 위에 AI 대화 매칭 계층을 연결한 버전입니다.
